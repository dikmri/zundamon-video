## 1. 画面構成

ずんだもん解説動画は「立ち絵が左右に立ち、中央の図解を見ながら会話し、下に字幕が出る」形がほぼ定番。
YMM4（ゆっくりMovieMaker4）が VOICEVOX 連携、口パク、目パチ、字幕を自動化しているため、この見た目が広まった。

| 要素 | 位置 | 既定のデザイン |
|---|---|---|
| 図解ボード | 中央上（x 380〜1540, y 100〜790） | 白地・角丸・ずんだ色の枠。左上に見出し |
| 四国めたん | 左下（頭〜腰が見える。ドリルヘアがボードの文字にかからない位置） | 坂本アヒル氏の立ち絵素材2.1（PSDTool）。表情12種・腕ポーズ7種・口パク・目パチ |
| ずんだもん | 右下（頭〜腰が見える） | 坂本アヒル氏の立ち絵素材V3.2（PSDTool）。表情13種・腕ポーズ10種・口パク・目パチ |
| 字幕 | 下中央、幅1260px | 白文字＋話者色の太い縁取り＋影（ずんだもん緑 / めたん桃）。強調語は黄色 |
| 章ラベル | 左上 | 緑の丸ラベル（例「② スペック」） |
| シリーズ名 | 右上 | 小さな白ラベル（`meta.series`） |
| 背景 | 全面 | 淡いずんだ色の斜めストライプ＋ドット |

白文字＋縁取り＋影は、ゆっくり解説系の字幕で最も読みやすいとされる組み合わせ。装飾を重ねすぎると逆に読みにくくなる。

## 2. 構成テンプレート

| 区間 | 目安 | 中身 |
|---|---|---|
| オープニング | 15〜25秒 | タイトルボード（`layout: title`、SE `title`）。ずんだもんの名乗りとテーマ紹介 →めたんの名乗りとテーマの言い換え →「今回は〇〇を順番に見ていく」と見通しを示す |
| 章タイトル | 3〜4秒 | `layout: chapter`、SE `jean`、`flash: true`、ヘッダー非表示。質問役が一言で章の問いを投げる |
| 章の本編 | 30〜45秒 | ボードを段階表示しながら解説。解説2〜3セリフごとに質問役の反応や質問を挟む |
| まとめ | 15〜25秒 | `layout: bullets` で3〜4項目。2人で交互に読み上げる |
| エンディング | 6〜10秒 | お礼、高評価・チャンネル登録の呼びかけ、クレジット |

章は3〜5個。各章は「問い → 結論 → 理由・具体例 → 反応」の順（PREP）にすると、質問役の一言から自然に始められる。

## 3. 役割分担と掛け合い

解説役と質問役の二人構成にすると、視聴者の疑問を質問役が先回りして聞き、解説役が答える流れが作れる。

- 作例（MiniMax H3）では、**めたん＝解説役**、**ずんだもん＝質問・反応・ボケ役**。オープニングと締めはずんだもんが仕切る。
- 逆に、ずんだもんが得意げに解説し、めたんが補足やツッコミを入れる回にしてもよい。題材に詳しい側を解説役にする。
- 質問役の仕事:
  - 視聴者が思いそうな疑問を口に出す（「最初と最後を決めたら、その間をつないでくれるのだ？」）
  - 相槌で区切りを作る（「なるほどなのだ」「注文して、できあがるのを待つ感じなのだ」）
  - 自分ごとの具体例にする（「ボクの写真とボクの声を渡せば…」）
  - 軽いボケで緩急をつける（お小遣いネタなど。1章に1回まで）
- 解説役が3セリフ以上続けて話さない。続くときは途中に反応を入れる。

## 4. 口調

### ずんだもん

- 公式設定: ずんだ餅の精。やや不幸属性があり、ないがしろにされることもしばしば。子どもっぽい高めの声。
- 一人称は「ボク」。語尾は「〜のだ」「〜なのだ」、疑問は「〜のだ？」「〜なのだ？」。
- 「です・ます」や「〜だよ」は使わない（キャラクターが崩れる）。
- 例: 「すごいのだ！」「それってどういうことなのだ？」「ボクにもできるのだ？」「ずんだ餅を食べる動画を考えてみるのだ！」

### 四国めたん

- 公式設定: 高等部二年生。常に金欠。趣味は中二病の妄想。誰にでも遠慮しないので、基本的にタメ口。一人称は「わたくし」。
- 語尾は「〜わ」「〜わよ」「〜ね」「〜かしら」「〜なの」。解説役では落ち着いたお姉さんとして話す。
- 例: 「いい質問ね」「大きく分けて、3つの作り方があるわ」「ふふ、そういうことよ」

## 5. テンポと字幕

- 話速（`cast.<名前>.speed`）: ずんだもん 1.2、めたん 1.15。解説動画は等速だと間延びする。
- 間（`meta.timing`）: セリフ間 0.25秒、シーン頭 0.5秒、シーン末 0.7秒。驚きやツッコミは前のセリフに `"pause": -0.1` を付けて食い気味にする。
- 1セリフは40字以内、字幕2行以内。長い説明は「結論の1文」と「補足の1文」に分ける。
- 読点「、」を打つと VOICEVOX の間も自然になる。「……」は溜めになる。
- 強調語は `**…**` で黄色にする。1セリフに1か所まで。
- 英字・数字・略語は `meta.reading` で読みを与える（`"2K": "ツーケー"`、`"API": "エーピーアイ"`）。最初の build のログ（`voicevox.synthesize` の text）で読み上げ文を確かめる。

## 6. 演出

### 表情と動き

表情は、そのキャラの次のセリフまで続く。平常に戻すときは `"face": "normal"` を明示する。

| 場面 | ずんだもん | 動き（`motion`） |
|---|---|---|
| 驚き | `surprised`（＋ポーズ `mouth`） | `jump` |
| 興奮 | `excited`（＋ポーズ `raise`） | `jump` |
| 喜び・お礼 | `happy` ＋ `"eyes": "smile"` | `jump` / `hop` |
| 得意げ・ボケ | `smug`（＋ポーズ `fold`） | `lean` |
| 困る・悲しい・不憫 | `cry` | `shrink` |
| 焦る | `panic` | `shake` |
| 考え中・質問 | `think`（＋ポーズ `think`） | — |
| 面倒・疲れた | `tired` | `shrink` |
| 怒る・ツッコミ | `angry` | `shake` |
| 内緒話 | `hush` / `whisper` | — |
| 納得 | `normal` | `nod` |

腕ポーズ（`pose`）も表情と同じく次の自分のセリフまで続く。ボードの中身を説明する質問役・解説役には、ずんだもんなら `point`（ボードを指す）、考え込む場面は `think`、ドヤ顔は `fold`（腕組み）、驚きは `mouth`（両手を口元に）、喜びは `raise`（バンザイ）が合う。
めたんの `point` / `present` は画面の外側を向くので、ボードを指す動作ではなく挨拶・紹介の身振りに使う。注意を促す場面は `think`（口元に指）。

| 場面 | めたん（表情 / ポーズ） |
|---|---|
| 解説の基本 | `normal` / `normal` |
| 挨拶・紹介 | `happy` / `present` |
| 得意げ | `smug` / `normal` |
| 注意・考え中 | `think` / `think` |
| 驚き | `surprised` / `normal` |

### 段階表示

ボードの要素は、それを説明するセリフと同時に出す。最初から全部見せると、視聴者は字幕より先にボードを読んでしまい、話を聞かなくなる。

- 数値やカード: `pop`（＋数字は `count`）
- 箇条書きの行: `left` / `up`
- 文中の一部を指す: `mark`（蛍光ペン）
- プロンプトやコードを打ち込む見せ方: `type`

### 効果音

| SE 名 | 使いどころ |
|---|---|
| `title` | オープニングのタイトル |
| `jean` | 章タイトル（`flash: true` と一緒に） |
| `pop` | ボードの要素が出るとき |
| `pico` | ツッコミ |
| `doon` / `jajean` | 大きな発表・結論 |
| `switch` | 話題の切り替え |
| `chanchan` | 締めのオチ |

鳴らしすぎると耳障りになる。1シーンに数回まで。

### BGM

魔王魂「アコースティック50」（穏やかで解説向き）を `bgm_volume` 0.1 前後で流す。声より目立たない音量にする。

## 7. 避けること

- 不確かな数値や噂を断定する。二次情報だけの数値は、出典を添えるか使わない。
- 実在の人物・企業のロゴや写真を無断で使う。ボードは図形・アイコン・文字で描く。
- 字幕3行以上、ボード1枚に要点5個以上の詰め込み。
- 東北ずん子・ずんだもんプロジェクトのガイドラインに反する内容（政治・宗教利用、キャラクターのイメージを著しく損なう内容など）。
